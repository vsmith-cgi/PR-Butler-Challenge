# Task Manager App

A simple task management application for organizing daily work with filters, priorities, and persistence.

## Features

- Add tasks with a selectable priority level
- Toggle tasks between active and completed
- Filter by all, active, or completed items
- Persist tasks in browser local storage
- Switch between English and French interface labels
- View live totals for all and completed tasks

## Setup

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Testing

```bash
npm run test
npm run test:coverage
```

The coverage command verifies that the project maintains at least 80% overall coverage before release.
